# Salesforce Engineering Hub

Maintained by the repository contributors
Requested visibility: **Public**
Project type: standalone Git repository containing skills, tools and documentation

## Objective
Provide a maintained, source-backed Salesforce engineering workspace spanning broad
product coverage and deeper investigation, implementation and verification workflows.

## Definition of done for initial repository
- Reviewed upstream pin and complete skill catalog.
- Original workflows with explicit tool and evidence boundaries.
- Passing local checks and documented synthetic evaluations.
- Repository content reviewed for publication; visibility verified separately on GitHub.
- Initial project contents committed and remote contents verified.

## Operational ownership
The project owner chooses the target org and business scope. The assistant investigates and implements
within that scope, reports actual evidence and respects service permissions. Live product
validation remains a separate milestone requiring the relevant test environments.

See [Roadmap](docs/ROADMAP.md) for subsequent milestones and acceptance criteria.

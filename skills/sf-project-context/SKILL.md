# Apply Salesforce Project Context

Read [runtime contract](references/runtime-contract.md) before operating.

## Workflow

1. Identify the current project and approved context records. Use only records whose
   scope matches the target project. Do not import another organization's facts.
2. Read the relevant architecture, requirements, decisions and handover. Classify
   each applicable statement as verified, superseded, stale or awaiting evidence.
3. Compare context with current source, metadata and observed results. Preserve
   approved business requirements while investigating conflicting implementation.
4. Confirm integration contracts, transaction boundaries, security requirements and
   acceptance criteria before proposing a change. Do not infer missing API names.
5. Keep organization-specific notes in its approved private project, outside this
   reusable skills repository. Save sanitized reusable lessons only after review.
6. Report evidence, gaps, affected assumptions and next action. Historical coverage
   numbers and earlier incident observations do not prove current readiness.

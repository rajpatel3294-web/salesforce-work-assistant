# Project context guide

This distribution includes no organization-specific historical profile.

For a real project, discover its approved requirements, architecture records,
integration contracts, component catalog and handover. Record source revision,
environment, observation date, ownership and validation status. Confirm business
acceptance criteria with the designated project owner when evidence is incomplete.

Never copy another organization's behavior, field names, record IDs, customer data,
credentials or historical decisions into a new project. Keep confidential evidence
in approved private storage. Use synthetic examples in reusable skills and tests.

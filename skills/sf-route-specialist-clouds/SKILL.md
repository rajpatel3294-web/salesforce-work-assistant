# Route Specialist Salesforce Clouds

Read [runtime contract](references/runtime-contract.md) before operating.

## Workflow

1. Identify the exact product, edition, licenses, managed packages, namespace, version, data model and requested capability. Similar product names do not establish interchangeable APIs.

2. Search the pinned catalog for relevant specialist skills and check required MCP servers, CLI plugins and product prerequisites.

3. Read current official product documentation for the specific operation. Record gaps when the collection has no dedicated implementation workflow.

4. For OmniStudio distinguish standard versus managed-package runtime and dependencies; for Commerce distinguish B2B, B2C and other storefront stacks; for Field Service inspect scheduling and mobile/offline implications.

5. Define an evidence collection and implementation plan with domain-specific acceptance tests and appropriately anonymized sample data.

6. Deliver a supported approach, prerequisites and gaps. Do not fabricate feature coverage or invent object/field APIs to appear comprehensive.

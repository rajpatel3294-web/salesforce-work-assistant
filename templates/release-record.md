# Release record

## Identity
Commit, target org/environment, manifest, package/API versions, release owner and window.

## Scope and dependencies
Changed components, dependencies, permission changes and activation steps.

## Validation evidence
Validation job, actual tests, counts, coverage scope, static findings and outstanding checks.

## Execution and recovery
Authorized actions, canary/waves, pause criteria, checkpoint, before-images and recovery owner.
Separate metadata rollback, data restoration and external side-effect compensation.

## Reconciliation
Selected, eligible, succeeded, failed, pending, duplicated and intentionally skipped records.
Verify business outcomes and downstream completion, not only job completion.
